# Syllabus2Career: Algorithmic Curriculum-to-Industry Skill Graph Engine

> Bridging academic semester syllabi with real-world industry career benchmarks.

## 🚀 Overview
**Syllabus2Career** is an advanced web-based curriculum intelligence platform designed for engineering undergraduates. Instead of treating university courses as isolated textbook modules, this application utilizes an algorithmic mapping engine to correlate academic coursework with live job market competencies, computing real-time skill gaps and personalized learning roadmaps.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS v4, Custom Glassmorphic CSS
* **Scripting:** Vanilla ES6 JavaScript (Modular architecture with dedicated data stores and computation engines)
* **Design System:** Responsive Single-Page Application (SPA) architecture with dynamic view routing
